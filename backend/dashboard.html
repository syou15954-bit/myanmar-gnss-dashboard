3D Globe (အလယ်ကမ္ဘာလုံး): Altitude ကို 2.4 သို့ အနည်းငယ် တိုးမြှင့်ပေးလိုက်သဖြင့် ကမ္ဘာလုံးသည် အလွန်အမင်း ကြီးမသွားဘဲ ဘေးဘက်ကတ်ပြားများနှင့် အချိုးအစား အထပ်အလွန် အံဝင်ခွင်ကျ ဖြစ်စေပါသည်။ Side Panels (ဘေးနှစ်ဘက် ကတ်ပြားများ): Font-weight နှင့် Readability ကို မြှင့်တင်ပေးထားပြီး စာသားများကို Dark Mode တွင် ပိုမိုထင်ရှားစွာ ဖတ်ရှုနိုင်စေရန် ပြုလုပ်ထားပါသည်။ Bottom Row (အောက်ခြေ Tabbed Card): အမြင့် (Height) ကို 150px အထိ အနည်းငယ် ထပ်ချဲ့ပေးထားသဖြင့် ခလုတ်များနှင့် ဇယားကွက်များ ပိုမိုကျယ်ဝန်းစွာ ပေါ်လာမည် ဖြစ်ပါသည်။ 💻 ပြင်ဆင်ထားသော backend/dashboard.html Code အပြည့်အစုံ အောက်ပါ Code ကို ကူးယူ၍ သင့်ပရောဂျက်ရှိ backend/dashboard.html ဖိုင်တွင် အစားထိုး သိမ်းဆည်းလိုက်ပါ - Ground Station Coverage Footprint (ရန်ကုန်စခန်း၏ ဆက်သွယ်နိုင်သော နယ်ဝန်းစက်ဝိုင်း): ရန်ကုန် ပင်မစခန်းပတ်လည်မှာ ဂြိုဟ်တုတွေနဲ့ တိုက်ရိုက်အချက်ပြလှိုင်း ဖမ်းယူနိုင်တဲ့ အကွာအဝေး (Horizon Visibility Circle / Footprint) ကို နေရောင်ခြည်စိမ်း သို့မဟုတ် အပြာရောင် စက်ဝိုင်းကွင်းလေးနဲ့ ကမ္ဘာ့မျက်နှာပြင်ပေါ်မှာ ထည့်သွင်းပြသနိုင်ပါတယ်။ Sub-Satellite Ground Tracks (ဂြိုဟ်တုများ၏ မြေပြင်လမ်းကြောင်းမျဉ်းများ): ဂြိုဟ်တုတွေ အာကာသထဲမှာ ပတ်နေတာအပြင် ကမ္ဘာ့မြေပြင်ပေါ်မှာ သူတို့ဖြတ်သန်းသွားမယ့် လမ်းကြောင်းမျဉ်းတွေ (Sine Wave Ground Tracks) ကိုပါ ကမ္ဘာ့မြေပုံပေါ်မှာ ခြယ်မှုန်းပြထားရင် ပိုပြီး နည်းပညာဆန်ဆန် လှပသွားပါမယ်။ Ionospheric TEC Heatmap Overlay (အိုင်ယွန်စဖီးယား လှိုင်းနှောင့်ယှက်မှု အပူချိန်မြေပုံ): အာရှ-ပစိဖိတ်ဒေသနဲ့ မြန်မာနိုင်ငံအထက်မှာ ဂျီပီအက်စ် အချက်ပြလှိုင်းတွေကို နှောင့်ယှက်နိုင်တဲ့ လျှပ်စစ်အိုင်းယွန်းသိပ်သည်းဆ (Total Electron Content - TEC) အခြေအနေကို ကမ္ဘာ့မျက်နှာပြင်ပေါ်မှာ အရောင်စုံ Heatmap ပုံစံ လွှမ်းခြုံပြသပေးနိုင်ပါတယ်။ Multi-Constellation Combined View (စနစ်အားလုံးကို ပေါင်းစပ်ပြသခြင်း): ယခုလောလောဆယ် ခလုတ်နှိပ်ပြီး တစ်ခုချင်းစီပြတာအပြင် "All Constellations" ဆိုတဲ့ ခလုတ်တစ်ခုထည့်ပြီး GPS (အပြာရောင်)၊ BeiDou (အနီရောင်)၊ Galileo (အစိမ်းရောင်) ဂြိုဟ်တုအားလုံးကို ကမ္ဘာလုံးပေါ်မှာ တစ်ပြိုင်နက်တည်း ပေါင်းစပ်ပြသပေးနိုင်တဲ့ Mode တစ်ခု ထည့်သွင်းပေးလို့ရပါတယ်။ Dynamic Sun Terminator (ကမ္ဘာ့ နေ့/ည ခြားနားချက် အရိပ်မျဉ်း): ကမ္ဘာကြီးရဲ့ ဘယ်ဘက်ခြမ်းမှာ နေရောင်ခြည်ကျရောက်နေပြီး ဘယ်ဘက်ခြမ်းမှာ ညဘက်ဖြစ်နေလဲဆိုတဲ့ နေရောင်ခြည် အရိပ်မျဉ်း (Day/Night Terminator Line) ကို အချိန်နဲ့တပြေးညီ တိုက်ရိုက်ပြောင်းလဲပေါ်လာအောင် လုပ်ထားပေးခြင်းက ကမ္ဘာလုံးကို အသက်ဝင်စေပါတယ်။ ဒီအထဲက အကြံပြုချက်တွေထဲမှာ ကြိုက်နှစ်သက်တဲ့ Feature တွေကို ကုဒ်ထဲမှာ ထပ်မံထည့်သွင်းချင်တယ်ဆိုရင် ပြောပြပေးပါ၊ ချက်ချင်း ရေးသားပြင်ဆင်ပေးပါမယ်။ Skyplot Canvas အရွယ်အစား တိုးမြှင့်ခြင်း: ညာဘက်အပေါ်ထောင့်က Skyplot Card ထဲမှာ ရှိနေတဲ့ ဆိုတဲ့ နေရာကို width="110" height="110" လို့ တိုးပေးလိုက်ပါက အဝိုင်းပုံ Skyplot လေး ပိုမိုကြီးမားလာပါမည်။Ground Station Coverage Footprint (ရန်ကုန်စခန်း၏ ဆက်သွယ်နိုင်သော နယ်ဝန်းစက်ဝိုင်း): ရန်ကုန် ပင်မစခန်းပတ်လည်မှာ ဂြိုဟ်တုတွေနဲ့ တိုက်ရိုက်အချက်ပြလှိုင်း ဖမ်းယူနိုင်တဲ့ အကွာအဝေး (Horizon Visibility Circle / Footprint) ကို နေရောင်ခြည်စိမ်း သို့မဟုတ် အပြာရောင် စက်ဝိုင်းကွင်းလေးနဲ့ ကမ္ဘာ့မျက်နှာပြင်ပေါ်မှာ ထည့်သွင်းပြသနိုင်ပါတယ်။ Sub-Satellite Ground Tracks (ဂြိုဟ်တုများ၏ မြေပြင်လမ်းကြောင်းမျဉ်းများ): ဂြိုဟ်တုတွေ အာကာသထဲမှာ ပတ်နေတာအပြင် ကမ္ဘာ့မြေပြင်ပေါ်မှာ သူတို့ဖြတ်သန်းသွားမယ့် လမ်းကြောင်းမျဉ်းတွေ (Sine Wave Ground Tracks) ကိုပါ ကမ္ဘာ့မြေပုံပေါ်မှာ ခြယ်မှုန်းပြထားရင် ပိုပြီး နည်းပညာဆန်ဆန် လှပသွားပါမယ်။ Ionospheric TEC Heatmap Overlay (အိုင်ယွန်စဖီးယား လှိုင်းနှောင့်ယှက်မှု အပူချိန်မြေပုံ): အာရှ-ပစိဖိတ်ဒေသနဲ့ မြန်မာနိုင်ငံအထက်မှာ ဂျီပီအက်စ် အချက်ပြလှိုင်းတွေကို နှောင့်ယှက်နိုင်တဲ့ လျှပ်စစ်အိုင်းယွန်းသိပ်သည်းဆ (Total Electron Content - TEC) အခြေအနေကို ကမ္ဘာ့မျက်နှာပြင်ပေါ်မှာ အရောင်စုံ Heatmap ပုံစံ လွှမ်းခြုံပြသပေးနိုင်ပါတယ်။ Multi-Constellation Combined View (စနစ်အားလုံးကို ပေါင်းစပ်ပြသခြင်း): ယခုလောလောဆယ် ခလုတ်နှိပ်ပြီး တစ်ခုချင်းစီပြတာအပြင် "All Constellations" ဆိုတဲ့ ခလုတ်တစ်ခုထည့်ပြီး GPS (အပြာရောင်)၊ BeiDou (အနီရောင်)၊ Galileo (အစိမ်းရောင်) ဂြိုဟ်တုအားလုံးကို ကမ္ဘာလုံးပေါ်မှာ တစ်ပြိုင်နက်တည်း ပေါင်းစပ်ပြသပေးနိုင်တဲ့ Mode တစ်ခု ထည့်သွင်းပေးလို့ရပါတယ်။ Dynamic Sun Terminator (ကမ္ဘာ့ နေ့/ည ခြားနားချက် အရိပ်မျဉ်း): ကမ္ဘာကြီးရဲ့ ဘယ်ဘက်ခြမ်းမှာ နေရောင်ခြည်ကျရောက်နေပြီး ဘယ်ဘက်ခြမ်းမှာ ညဘက်ဖြစ်နေလဲဆိုတဲ့ နေရောင်ခြည် အရိပ်မျဉ်း (Day/Night Terminator Line) ကို အချိန်နဲ့တပြေးညီ တိုက်ရိုက်ပြောင်းလဲပေါ်လာအောင် လုပ်ထားပေးခြင်းက ကမ္ဘာလုံးကို အသက်ဝင်စေပါတယ်။အကုန်ထပ်သွင်းပေးပါ တောင်းဆိုထားသည့် အဆင့်မြင့် Feature အားလုံး (Skyplot Canvas အရွယ်အစား တိုးမြှင့်ခြင်း၊ Yangon Ground Station Coverage Footprint ကွင်းလေးများ၊ Sub-Satellite Ground Track မျဉ်းများ၊ Ionospheric TEC Heatmap, All Constellations Combined View ခလုတ် နှင့် Dynamic Sun Terminator အရိပ်မျဉ်းများ) အကုန်အစင် ပေါင်းစပ်ထည့်သွင်းပေးထားသော backend/dashboard.html ကုဒ်အပြည့်အစုံကို အောက်တွင် ဖော်ပြပေးလိုက်ပါပြီ။ 💻 အဆင့်မြှင့်တင်ထားသော backend/dashboard.html Code အပြည့်အစုံ အောက်ပါ Code ကို ကူးယူ၍ သင့်ပရောဂျက်ရှိ backend/dashboard.html ဖိုင်တွင် အစားထိုး သိမ်းဆည်းလိုက်ပါ -
